# CA2_SEM2_ProjectTweets
Project: Tweets Analysis

The aim of this project is to leverage a large-scale dataset stored across two NoSQL databases.

Data processing will be conducted in a Spark environment, utilizing Spark SQL for efficient querying and manipulation.

Following the removal of irrelevant data, a comparative performance analysis of the two databases will be performed to evaluate their efficiency and suitability.

Additionally, the project will include sentiment analysis on the Twitter texts to extract insights into public opinion.

Finally, a time series analysis will be conducted to identify trends and patterns over time, along with forecasting for 1 week, 1 month, and 3 months to provide predictive insights.
